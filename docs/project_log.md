- 2026-10-28 (власник): тексти уроків у `content/<мова>/`, UI-тексти в `strings.xml`; мовно-незалежні дані в `content/common/`.

- 2026-10-28 (власник): робоча назва «Шаховий тренер» / «Chess Trainer», простір імен коду `org.chesstrainer.*`; остаточна назва й `applicationId` до етапу 5.
- 2026-10-28 (Архітектор): правила лише через інтерфейс `ChessRules`; кандидат chesslib, запасний варіант власна реалізація.
