# Ручні сценарії на пристрої (QA)

Пристрій: Samsung SM-S928B (Android 17 за `ro.build.version.release`), серійний `RZCX326349A`, збірка `org.chesstrainer.app.debug`.
Назви кнопок нижче взято з `app/src/main/res/values-uk/strings.xml` (інтерфейс українською).

Позначки: **[adb]** QA виконує сама через adb і журнал (результати в `tests/DEFECTS.md`, `tests/results/`); **[власник]** потрібні дії в застосунку, їх виконує власник за чек-листом. Біля кожного пункту поле «Результат» заповнює виконавець: `ОК` / `ДЕФЕКТ № …` / `н/в` (не виконано).

Перед початком: встановлена debug-збірка з поточного `main` (`./gradlew :app:installDebug`), екран розблоковано, автообертання ввімкнене.

Корисні команди (PowerShell або Git Bash, platform-tools у PATH):

```
adb shell pidof org.chesstrainer.app.debug                      # PID застосунку
adb shell pidof org.chesstrainer.app.debug:engine               # PID рушія
adb shell run-as org.chesstrainer.app.debug kill <PID>          # вбити процес
adb shell am force-stop org.chesstrainer.app.debug              # «вбити» застосунок повністю
adb logcat -d | findstr /i "chesstrainer EnginePrototype AndroidRuntime"
```

## M1a. Те саме через adb [adb]

Kill процесу застосунку посеред партії (`adb shell am force-stop …`) і перевірка через `adb shell run-as org.chesstrainer.app.debug` вмісту БД (`databases/`) без запису: лише читання кількості записів. Результат у `tests/results/`.

## M4. Вбивство процесу рушія [adb + власник]

[adb] Виконує QA: запустити партію (потрібен один хід власника, або діалог рівня — дії в UI роблять власник), далі:

```
adb shell pidof org.chesstrainer.app.debug:engine
adb shell run-as org.chesstrainer.app.debug kill <PID>
```

| № | Кроки | Очікувано | Результат |
|---|---|---|---|
| 4.1 | Партія, хід людини зроблено, рушій «думає»; вбити процес `:engine`. | Застосунок живий; повідомлення «Шаховий рушій несподівано зупинився. Вашу партію збережено…» (`game_engine_crashed`); кнопка «Спробувати знову» перезапускає рушій і партія триває; ходи не втрачені. | |
| 4.2 | Вбити `:engine`, коли хід за людиною (рушій простоює). | Застосунок живий; наступний хід людини → рушій відповідає (самовідновлення або «Спробувати знову»). | |
