# MASTER_SPEC — Шаховий тренер для Android

Єдине джерело вимог для всіх агентів. Якщо інші документи або чати суперечать цьому файлу, діє цей файл. Зміни вносить лише Архітектор після погодження з власником проєкту.

## 1. Мета

Безкоштовний застосунок з відкритим кодом для Android, який навчає шахів від нульового рівня до сильного клубного гравця (орієнтир 2200+ Elo). 2200+ є метою розвитку гравця, а не гарантованим результатом курсу.

## 2. Обмеження (обов'язкові)

- Нуль додаткових фінансових витрат на розробку й підтримку. Разова плата за акаунт Google Play (приблизно 25 $) є єдиним винятком.
- Код відкритий, ліцензія GPL-3.0 (сумісна зі Stockfish, GPLv3).
- Без платних API, платних серверів і платних голосів.
- ШІ не викликається всередині застосунку. Пояснення будуються на аналізі Stockfish та шаблонах або готуються заздалегідь як файли.
- Усі зовнішні ресурси (шрифти, фігури, звуки, бази задач) перевіряються на сумісність ліцензії й записуються в `docs/THIRD_PARTY.md`.

## 3. Мови

Перший реліз: українська (uk) та англійська (en). Усі тексти лише через `strings.xml` (`values/` для en, `values-uk/` для uk). Жодних рядків у коді.

## 4. Платформа й технології

| Напрям | Рішення |
|---|---|
| Мова | Kotlin |
| UI | Jetpack Compose |
| Рушій | Stockfish (UCI), інтеграція через NDK |
| Шахова модель | FEN, PGN, UCI |
| Правила й легальні ходи | Перевірена відкрита бібліотека (кандидат: chesslib; перевірити ліцензію) |
| Локальні дані | Room |
| Звук | Android TTS + відкриті звукові ефекти |
| Тести | Unit, integration, UI |
| Збірка | Gradle, GitHub Actions (безкоштовний рівень) |

Мінімальна версія Android визначається Архітектором на етапі 1 (рекомендовано API 26+).

## 5. Етапи

1. **Архітектура й прототип:** ця специфікація, структура модулів, дизайн-система, критерії готовності.
2. **MVP, офлайн:** дошка, легальні ходи, гра проти Stockfish з рівнями складності, збереження партій, базові задачі.
3. **Навчання:** курс за рівнями, задачі, повторення, дебюти, ендшпілі, розбір партій.
4. **Полірування:** анімації, озвучення, переклади, оптимізація, тести.
5. **Публікація:** Google Play (за бажанням також F-Droid).

Онлайн-гра поза межами першого релізу. Якщо буде потрібна пізніше, розглядаються лише безкоштовні варіанти (Lichess API з його лімітами або peer-to-peer).

## 6. Функції MVP

- Дошка з легальними ходами, шахом, матом, патом, рокіровкою, взяттям на проході, перетворенням пішака.
- Гра проти Stockfish з вибором складності.
- Аналіз позиції, оцінка переваги.
- Імпорт і експорт PGN, завантаження з FEN.
- Збереження партій і прогресу локально.
- Тактичні задачі (бази з відкритою ліцензією, наприклад CC0).
- Світла й темна теми, мінімалістична графіка.
- Повна робота без інтернету.

## 7. Навчальна система

- Діагностика початкового рівня.
- Рівні: початківець, любитель, клубний гравець, сильний гравець. Критерії переходу задає Методист.
- Теми: правила, тактика, стратегія, дебюти, ендшпілі.
- Підказки трьома кроками: натяк, напрямок, конкретний хід.
- Інтервальне повторення помилок.
- Розбір партій: критичні моменти, класифікація помилок, пояснення людською мовою, що спираються на варіанти рушія, а не на здогадки.

## 8. Ролі агентів

| Роль | Відповідає за | Не робить |
|---|---|---|
| Архітектор | Специфікація, модулі, контракти, інтеграція, стандарти | Не змінює перевірену шахову логіку без тестів |
| Шахове ядро | Правила, інтеграція Stockfish, аналіз, FEN/PGN/UCI | Не чіпає UI та контент |
| Android і UI | Екрани, навігація, теми, локальне збереження, доступність | Не змінює API шахового ядра |
| Навчання і контент | Програма, задачі, уроки, коментарі, переклади uk/en | Не пише код ядра |
| QA | Тест-кейси, регресія, звіти про дефекти | Не виправляє код самостійно, лише повідомляє |

Один агент не змінює модулі іншого. Потрібна зміна чужого модуля оформлюється запитом у `project_log.md`.

## 9. Структура репозиторію

```
docs/            специфікація, журнал, THIRD_PARTY.md
app/             Android-застосунок (UI)
core-chess/      шахове ядро та інтеграція Stockfish
learning/        навчальна логіка й адаптація
content/         уроки, задачі, переклади
tests/           тести
```

## 10. Правила взаємодії

- Контракти між модулями (інтерфейси, формати даних) фіксуються в `docs/CONTRACTS.md` і не змінюються без запису в журналі.
- Іменування: Kotlin за офіційним стилем, пакети `org.<назва>.chesstrainer.<модуль>`.
- Кожен модуль у своїй Git-гілці (`feature/<модуль>`), у `main` через перевірку.
- Кожна зміна шахової логіки супроводжується окремими тестами.
- Після кожного етапу: збірка, всі тести, оновлення `project_log.md`.
- Заборонено довільно перейменовувати класи, змінювати формат даних чи переписувати чужі модулі.

## 11. Критерії готовності MVP

- Усі правила шахів проходять тести (включно з крайовими випадками: рокіровка, взяття на проході, пат, повторення позиції, правило 50 ходів).
- Гра проти Stockfish стабільна на кількох пристроях і розмірах екрана.
- Усі видимі тексти доступні в uk та en.
- Робота без інтернету.
- Усі зовнішні ресурси мають перевірену ліцензію.

## 12. Публікація в Google Play

- Акаунт розробника, верифікація.
- Політика конфіденційності (застосунок не збирає дані; зазначити це).
- Актуальні вимоги до тестування нових акаунтів перевірити в Play Console перед запуском.
- Сторінка застосунку: опис, скриншоти, іконка, мови uk/en.
- Вказати відкритий код і ліцензію GPL-3.0.

## 13. Відкриті питання

- Мінімальна версія Android.
- Вибір бібліотеки правил (перевірити ліцензію та підтримку).
- Назва застосунку та ідентифікатор пакета.
- Джерела навчального контенту (ліцензії).
